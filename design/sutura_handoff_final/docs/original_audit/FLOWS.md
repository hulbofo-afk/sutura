# Parcours UX prioritaires

## Parcours 1 — Activation créateur

Connexion → accueil → créer une collection → ajouter un modèle → créer un test → ajouter une question → publier → partager.

Objectif : atteindre le premier lien partageable avec le moins de décisions possible.

## Parcours 2 — Répondant public

Lien public / QR → présentation du test → questions → validation des champs obligatoires → envoi → confirmation.

Règle : aucune connexion ou création de compte ne doit interrompre ce parcours.

## Parcours 3 — Retour créateur

Accueil → test actif → analytics → détail d’une question → recommandations → action suivante.

Le designer doit montrer la différence entre une donnée descriptive et une recommandation exploitable.

## Règles d’interaction

- Toujours afficher la conséquence d’une action destructive ou irréversible.
- Après publication, confirmer la nouvelle URL publique et le statut actif.
- Après upload, montrer miniature, nom, progression et possibilité de remplacer.
- Les erreurs API doivent être traduites en message humain, sans afficher le code brut.
- Une action réseau doit avoir un état désactivé ou progressif pour éviter les doubles envois.
- Les réponses publiques doivent rester dans le formulaire après une erreur.
